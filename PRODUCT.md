# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Tech recruiters, engineering managers, and startup founders evaluating frontend and web development capabilities for engineering roles and collaboration opportunities.

## Product Purpose

A personal developer portfolio showcasing real projects, core technologies, and engineering philosophy with distinctive craft, bilingual internationalization (`es`/`en`), dark/light theme versatility, and high performance.

## Positioning

A detail-oriented frontend developer with a strong systems engineering background, specializing in modern web ecosystems (Astro, React, Next.js, Tailwind CSS) with a focus on UI polish, clean code architecture, and high technical quality.

## Operating Context

Evaluated across desktop and mobile devices by recruiters and hiring managers who scan quickly for project quality, live demos, GitHub repositories, and tech stack proficiency.

## Capabilities and Constraints

- **Stack**: Astro 7, Bun, Tailwind CSS v4, Biome, Tabler Icons (`@tabler/icons-astro`).
- **i18n**: Fully localized in Spanish (`es`) and English (`en`) with URL routing (`/` and `/en`).
- **Theme**: Client-side theme switching (System, Dark, Light) with persistent preference.
- **SSG**: Static site generation deployed to `gustadev.app`.

## Brand Commitments

- **Name**: Gustavo Sequeiros (@gustadev121 / Luis Gustavo).
- **Voice**: Professional, authentic, enthusiastic, innovative, and detail-oriented.
- **Visual Tone**: Clean modern developer aesthetic with refined typography and subtle ambient lighting, avoiding generic AI clichés.

## Evidence on Hand

- Real projects with live URLs, GitHub repositories, and webp media assets (`acm`, `classroom`, `exoplanets`, `knowledge-wardens`, `techart`).
- Real profile image and social links (GitHub, LinkedIn, Email).

## Product Principles

1. **Craft Over Noise**: Clear visual hierarchy, fast load times, and authentic presentation over superficial gimmicks.
2. **Accessible by Default**: Complete bilingual parity, keyboard navigable docks, dark/light contrast, and reduced-motion respect.
3. **Artifact-Led Experience**: Highlighting real code and interactive projects from the initial view.

## Accessibility & Inclusion

- WCAG 2.2 compliant navigation, semantic tags, title tags on visual assets, and high contrast in both color modes.
